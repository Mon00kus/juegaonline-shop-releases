# JuegaOnline.Shop Releases

Este repositorio contiene las releases de las aplicaciones de juego de **JuegaOnline.Shop**.

## Aplicaciones Disponibles

### 🎱 Bingo Online

- **Versión actual:** V1.0.0
- **Plataforma:** Android
- **Descripción:** Aplicación de bingo en línea con sorteos en tiempo real, patrones de juego y premios.
- **Archivo:** `app-release.apk`

## Cómo instalar

1. Descarga el archivo APK de la versión deseada
2. En tu dispositivo Android, habilita "Instalar desde fuentes desconocidas" en Configuración
3. Abre el archivo APK y completa la instalación

## Requisitos

- Android 6.0 (Marshmallow) o superior
- Conexión a internet para jugar

## Acerca de JuegaOnline.Shop

JuegaOnline.Shop es una plataforma de juegos de azar en línea donde podrás participar en sorteos de bingo desde cualquier lugar.
